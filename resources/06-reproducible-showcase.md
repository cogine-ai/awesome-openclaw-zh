# 三份可复刻成果：经验卡、手绘战报、喜剧追逐

> 先打开实际产物，再下载输入和复现脚本。选择一个任务，把它改成自己的版本。

这轮由 Cogine 整理三个具体流程。示例保留必要输入、固定版本的上游工具、许可和复现入口；它们分别验证卡片创建与修订、公开仓库数据渲染和分镜检查/编译。模型对话、角色图像和最终视频是否完成，以各篇说明为准。

## 先做哪一个

- **只想快速体验：**先用经验卡的固定输入跑一次，再换成自己真实做成的事。编辑建议与本人确认的事实分开保存。
- **想展示一个看得见的成果：**用公开数据生成手绘战报；保留采集时间和统计范围，不把单个仓库当作整个公司的经营表现。
- **想做创作内容：**先检查喜剧追逐的动作与站位，再准备图像和视频服务。分镜包通过检查不代表已经产出成片。

每个样例目录都附有自己的复现入口。先按案例的 Python 版本与命令运行，再逐项替换输入；不要只下载一张图片就期待重新生成。

## 改成你自己的成果

经验卡可用于复盘一次排错、一次沟通或一次创作。手绘卡只使用你有权公开的数据。追逐故事优先使用原创角色与场景，保留工具许可和作者署名。
