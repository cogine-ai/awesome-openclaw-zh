# 把 OpenClaw 用进真实工作：从第一份周报开始

发布正文草稿；建议标签 `workflows-2026-11-07`。以下正文可用于 GitHub Release，仓库与网站改动合并上线后发布。

---

装好 OpenClaw 后，先完成手上的一件事。

这次我们把中文手册的入口整理成了三条路线：

- **飞书与企微办公**：用五天笔记整理一份周报，再换成自己的工作记录。
- **AI 编程协作**：分清 CLI 文本响应与 ACP 持续编码，给 Codex / Claude Code 一个范围明确的小任务。
- **部署与运行排错**：按 Windows / WSL2、Mac 或 Linux 找到对应步骤。

本期先做周报：[打开完整练习](https://www.opcboost.com/quickstart/03-weekly-report/)。里面有示例笔记、整段提示词、参考输出和修改方法。已能与 OpenClaw 对话就可以开始，飞书和企微按需接入。

练习特意保留了几个常见情况：页面已上线，视频还没做，客户 Logo 许可还没确认。让草稿准确表达这些状态，才方便交给同事继续工作。
