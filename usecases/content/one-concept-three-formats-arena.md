# 一个知识点，三种讲法：卡片、漫画、短片内容擂台

> 用同一份事实底稿做三种表达，先比准确性，再用真实阅读反馈决定下一期。

## 来源与验证说明

- 类型：Cogine 原创实验；2026-10-11。
- 灵感：Easel 的知识卡片/漫画产物与 OpenClaw 的视频生成能力。
- 状态：完整选题与产物约定；本轮未调用付费图像/视频服务，也未发布投票。
- 与内容工厂的区别：三条路线共享事实底稿和评分口径，目标是探索哪种表达更容易理解，不是批量分发。

## 前置条件与成本

第一轮只生成文本分镜即可。做图片时准备图像生成工具，做短片时准备 OpenClaw `video_generate` 支持的后端与额度。生成媒体的费用先确认，文案不能冒充已生成的视频。

## 快速体验版（先跑一轮）

```text
请围绕“为什么 Agent 要先小步验证，再扩大自动化”做三种表达。
本轮只做文字素材包，不调用付费媒体、不发布内容。
统一事实底稿：
- 工具能调用，不代表完整任务已经跑通。
- 前置权限、数据质量和外部服务状态都会影响结果。
- 一个具体输入和可核对产物，比一句“效果很好”更容易验证。
这三句是本次创作底稿，不是引用的实验结论。

在当前工作目录输出：
1. facts.md：三句话、使用范围、不能宣称的结论。
2. card.md：一个标题、三张知识卡文字、每张画面草图说明。
3. comic.md：固定角色“龙虾助手和同事”，四格故事；最后一格给出一次小实验。
4. clip.md：30秒竖屏分镜，逐镜时长/画面/旁白，总计30秒。
5. scorecard.md：事实准确、读者能否复述、是否知道下一步、制作成本四项；分数先留空。
6. share.md：三种内容各一条发布草稿，统一署名“OPCBoost · by Cogine”，链接到案例库。
先生成底稿再制作表达。原文没有的成功率、成本节省、投票结果都不要补造。
```

## 制作媒体与比较反馈

- 卡片/漫画：可参考 [Easel 论文转漫画](../creative/easel-paper-to-detective-comic.md)，先检查分镜与事实再生成图片。
- 短片：可参考 [原生视频生成](../creative/native-video-generation-chat.md)，拆成后端支持的短镜头；30 秒脚本不表示某后端支持一次生成 30 秒。
- 三种版本使用同一目标受众和相近曝光条件；先小规模测试，记录访问、收藏、模板复制和读者复述。
- 流量来源和样本数不同就分别展示，不用总点击量断言表达形式优劣。

## 成功标准与失败排查

- [ ] 每个表达都保留同一事实，不凭空增加“实测证明”。
- [ ] 短片脚本的镜头时长合计 30 秒；生成片段另按后端限制验收。
- [ ] 评分表初始为空，后续只填写实际记录的成本和反馈。
- [ ] 媒体失败时保留文本素材包与错误原因，可先发布人工审核的文字内容。

## 延伸玩法

下一期可以换成一个新 Skill 的用途、一次失败复盘或公司公开技术文章。选题和素材同时积累，逐步形成有固定角色的中文 Agent 内容系列。
