# 用 OpenClaw 把五天零散进度整理成一份周报

周五要交周报，进度还散落在每天的笔记里。把下面的任务复制给 OpenClaw，先得到一份能核对的草稿，再换成自己的工作记录。

开始前，确认已经能与 OpenClaw 对话。可以使用浏览器控制台，也可以使用已接好的飞书或企业微信机器人。第一次练习只用虚构笔记，不需要安装额外 Skill 或连接工作系统。

## 先看会得到什么

这份练习里，小林负责产品介绍页，小周负责配图。页面已经上线，但视频仍未制作，客户 Logo 也还没获得使用许可。周报要让同事一眼看出这些状态：

> **本周完成**：产品介绍页上线，手机检查完成；暂时使用自制配图。  
> **仍有卡点**：客户 Logo 使用许可未确认；视频账号未配置，视频未制作。  
> **下周计划**：小林补充常见问题，小周提供配图第二版；交付日期待确认。

这是按练习材料编写的参考摘要。实际生成的措辞可以不同，完成状态和负责人应与输入一致。

## 复制这个任务

把下面整段粘贴到 OpenClaw 的对话中：

```text
请把下面五天的笔记整理成一份中文工作周报，给同事阅读。

输出：
1. 本周完成：按工作成果合并重复进度，最多 3 条。
2. 进行中与卡点：列清当前状态、需要的帮助。
3. 下周计划：用表格列出事项、负责人、截止时间。
4. 待确认：单独列出缺失的负责人、日期或尚未确认的结果。

写作要求：
- 总长度控制在 500 字以内，语气直接。
- 只使用笔记中的事实，不把“计划”“准备”“等待”写成完成。
- 缺少负责人或日期时写“待确认”。
- 只在当前对话返回草稿，不调用工具或向其他人发送。

练习笔记（虚构）：
周一：小林完成产品介绍页初稿，待团队评审。小周开始整理配图。
周二：团队通过文案。小周交付自制配图第一版。客户 Logo 使用许可仍未确认，先不上客户 Logo。
周三：小林完成页面制作，测试链接可以打开。还没有做手机检查。
周四：小林完成手机检查并修复按钮换行问题。视频账号还没配置，视频没有制作。
周五：小林确认介绍页已上线，目前用自制配图。还没有收集到访问、注册或客户反馈数据。
下周：小林补充常见问题；小周提供配图第二版。两件事都没约定交付日期。客户 Logo 许可需要继续跟进，负责人未定。
```

## 核对这几个地方，再换成自己的笔记

页面应写“已上线”，视频应写“未制作”；不能出现访问增长、注册转化或客户好评。下周两项任务的负责人分别是小林、小周，日期均待确认；Logo 许可的跟进人也待确认。

确认这份草稿表达清楚后，把“练习笔记”替换成自己的五天进度。可以继续发一句：

```text
把上面的周报压缩为适合在群里阅读的 200 字版本。
保留本周完成、卡点和下周计划，不增加新的事实。
```

如果它把某个状态写错，直接指出原句，例如：“周四明确写视频没制作，请修正完成状态。”
